# 🦷 BrightSmile Dental Care

A modern full-stack Dental Clinic Management System developed using **React + Vite** for the frontend and **Spring Boot** for the backend.

## 📌 Project Structure

```text
BrightSmile-Dental-Care/
│
├── frontend/          # React + Vite Frontend
├── backend/           # Spring Boot Backend
└── README.md
```

## ⚙️ Getting Started

### Clone Repository

```bash
git clone https://github.com/yourusername/brightsmile-dental-care.git

cd brightsmile-dental-care
```

---

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

Application runs at

```
http://localhost:3000
```

---

## Run Backend

```bash
cd backend
./mvnw spring-boot:run
```

Backend runs at

```
http://localhost:8080
```
