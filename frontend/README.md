# BrightSmile Dental Care - Frontend

Frontend of BrightSmile Dental Care developed using React and Vite.

---

## Tech Stack

- React
- TypeScript
- Vite
- CSS3

---

## Features

- Responsive Design
- Home Page
- Services
- About
- Doctors
- Gallery
- FAQ
- Testimonials
- Appointment Booking
- Contact Form

---

## Installation

Install dependencies

```bash
npm install
```

Run project

```bash
npm run dev
```

Application runs on

```
http://localhost:3000
```

---

## Build

```bash
npm run build
```
